# Inglés Profesional · 4/11: comparativos y superlativos

> Anterior: [Tutoría 3/11](2026-11-03_tutoria-past-simple-continuous-incidentes.md) · Siguiente: [Tutoría 17/11: causa, propósito y resultado + simulacro](2026-11-17_tutoria-cause-purpose-result-y-simulacro.md) · Profesora: Cristina Gómez Monsalve

> [!important] Lo imprescindible
> - **Adjetivo corto (1 sílaba):** *-er* / *the -est* (*fast → faster → the fastest*).
> - **Adjetivo largo (2+ sílabas):** *more … / the most …* (*more reliable → the most reliable*).
> - **Irregulares:** *good → better → the best* · *bad → worse → the worst* · *far → farther/further → the farthest/furthest*.
> - **Nunca doble comparativo:** ✗ *more faster* → ✓ *faster*.

## Reglas
| Regla | Ejemplo |
|---|---|
| Corto + *-er* / *-est* | *cheap → cheaper → the cheapest* |
| Termina en *-e*: solo *-r / -st* | *large → larger → the largest* |
| Consonante-vocal-consonante: duplica | *big → bigger → the biggest* |
| Termina en *-y*: *-ier / -iest* | *easy → easier → the easiest* |
| Largo: *more / the most* | *more expensive → the most expensive* |
| Inferioridad | *less … than* / *the least …* |
| Igualdad | *as … as* (*as fast as*) / *not as … as* |
| *old* | *older / the oldest*; *elder* solo para familiares (*my elder brother*) |
| *Far* | *farther* (distancia física) / *further* (más, adicional: *further information*) |

## Estructuras extra
- ***The more …, the more …:*** *The more RAM you have, the faster it runs.*
- Énfasis: ***by far the most …*** (*It is by far the most powerful server.*)
- Cambio progresivo: ***increasingly …*** (*The attacks are becoming increasingly sophisticated.*)
- Comparativo + *than*: *This SSD is faster than that HDD.*

## Errores típicos corregidos
- ✗ *more faster*, ✗ *the most fastest*.
- ✗ *good than* → ✓ *better than*.
- ✗ *as … than* → ✓ *as … as*.

## Dudas y cosas sin confirmar
- Las respuestas de los ejercicios de la clase no están todas reconstruidas; los ejemplos de arriba están basados en las reglas dadas.
