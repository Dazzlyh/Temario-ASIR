## 1 · Confidencialidad
```bash
echo 'mis nóminas 2026' > privado.txt
chmod 600 privado.txt
ls -l privado.txt                 # -rw------- : solo tú
openssl enc -aes-256-cbc -pbkdf2 -in privado.txt -out privado.enc
cat privado.enc                   # Salted__... ilegible
openssl enc -d -aes-256-cbc -pbkdf2 -in privado.enc    # misma clave, vuelve
```
Desglose de `openssl enc -aes-256-cbc -pbkdf2 -in privado.txt -out privado.enc`:
- `enc`: subcomando de cifrado/descifrado simétrico · `-aes-256-cbc`: algoritmo AES, clave de 256 bits, modo CBC · `-pbkdf2`: deriva la clave desde la contraseña con PBKDF2 (más robusto frente a fuerza bruta) · `-in`/`-out`: fichero de entrada/salida · pide contraseña por teclado · la salida empieza por `Salted__` (sal aleatoria) · `-d` = descifrar (misma clave).
- Permisos = que no lo lea quien no debe; cifrado = que aunque lo abran no lo entiendan.

## 2 · Integridad, parte 1: el sistema vigila sus ficheros
```bash
sudo apt install -y hello debsums
sudo debsums hello                                        # cada fichero: OK
echo malicioso | sudo tee -a /usr/share/doc/hello/copyright
sudo debsums hello                                        # ese fichero: FAILED
```
`debsums` compara los ficheros instalados de un paquete con las sumas del paquete.

## 3 · Integridad, parte 2: comprobar una descarga antes de instalar (PuTTY)
```powershell
Get-FileHash .\putty-64bit-installer.msi -Algorithm SHA256     # Windows
```
```bash
shasum -a 256 putty.dmg      # macOS  (en Linux: sha256sum)
```
Comparar **carácter a carácter** con el hash publicado en putty.org; si no coincide, la descarga está manipulada: **no instalar**. En clase se hizo con el .exe.

## 4 · Disponibilidad: tirar el servicio y medir el MTTR
```bash
curl -I http://localhost          # 200 OK: disponible
sudo systemctl stop apache2       # lo tiramos · cronómetro EN MARCHA
curl -I http://localhost          # no responde: caído
sudo systemctl start apache2      # lo levantamos
curl -I http://localhost          # 200 OK · paras el cronómetro
uptime                            # cuánto lleva vivo = tu disponibilidad
```
MTTR = tiempo medio de recuperación (Mean Time To Repair/Recover). Aquí: el tiempo entre parar y que vuelva a responder.
